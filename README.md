# Café Origen: Analítica de ventas

Proyecto en JavaScript para analizar el historial de ventas de Café Origen.

## Estructura
- `src/datos.js`: arreglo `ventas` con los 12 registros originales
- `src/explorar.js`: exploración inicial de los datos
- `src/analitica.js`: cálculos (se completará en los siguientes retos)
- `bitacora.md`: diccionario de datos y casos borde
